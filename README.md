# AgroConnect – Farmer E-Commerce Marketplace

AgroConnect is a full-stack marketplace where farmers and agri-suppliers sell seeds, fertilizers, tools, equipment and fresh produce directly to customers. Built with **Flask + SQLite** and plain **HTML/CSS/JavaScript** (no React, Vue or Tailwind).

## Features

- Shop with category filters, price range, rating, search, sorting and pagination
- Product details with gallery, reviews and ratings, related products
- Cart and wishlist (stored in `localStorage`, synced with the server at checkout)
- 4-step checkout: address → delivery → payment → review
- Delivery availability check by pincode
- Orders, order details and a tracking timeline
- Customer, Seller and Admin roles
  - Seller dashboard: add/edit/delete products (image upload), manage orders, Chart.js sales charts
  - Admin dashboard: approve products, manage users and categories, platform charts
- Security: hashed passwords, CSRF protection, upload validation (extension + magic bytes), role-based access
- Simulated payments (COD / UPI / Card with Luhn check). No card data is stored
- Indian demo data (₹, GST 5%, free delivery above ₹2000, otherwise ₹50)

## Tech stack

Python 3, Flask, SQLite, Jinja2, vanilla JS, CSS (Inter font, black + green theme in `static/css/theme.css`), Chart.js and Font Awesome via CDN.

## Images (read this)

The zip ships with **subject-specific artwork for every product, category and blog post** (`static/images/art/`, generated by `tools/make_art.py`): tomato art for tomato products, a tractor for the tractor, a drip line for the drip kit and so on. It works offline and never mismatches.

These are illustrations, not photographs (I could not download Unsplash photos where this was built). For real HD photography, add a free Unsplash key and download photos; **a downloaded photo automatically replaces the artwork for that product**.

```bash
# 1. free key from https://unsplash.com/developers  (Access Key)
# Windows PowerShell:  $env:UNSPLASH_ACCESS_KEY="your_key"
# macOS/Linux:         export UNSPLASH_ACCESS_KEY="your_key"
python download_images.py          # downloads static/images/** + CREDITS.txt
```

Then open **`image-checklist.html`** in your browser. It lists Product → filename → photo so you can confirm every pair by eye. If one is wrong:

```bash
python download_images.py --only tomato-seeds --pick 2 --force
```

The free key allows 50 requests/hour; rerun later and finished files are skipped. You can also drop your own JPGs into `static/images/` using the same file names. Keep `CREDITS.txt` (Unsplash attribution).

## Language selector

Globe dropdown in the navbar: English, తెలుగు, हिन्दी, தமிழ், ಕನ್ನಡ, मराठी. Choice is stored in `localStorage("language")` and re-applied on every page. Translations live in `static/js/i18n.js` (English text is the key, so templates need no extra markup). English, Telugu and Hindi cover navigation, hero, categories, shop filters, cart, checkout, footer and toasts; Tamil, Kannada and Marathi cover navigation and the most common labels. Product names and descriptions come from the database and stay in English.

## Interfaces: Customer, Farmer, Seller

Sign-up offers three account types and AgroConnect now keeps their catalogue and navigation separate. The account type controls which categories, products and tabs are shown.

- **Customer** – sees consumer-facing categories such as Fresh Vegetables, Fruits, Grains & Pulses and Organic Produce, plus shopping, wishlist, cart, orders and deals.
- **Farmer** – sees only farm-input categories such as Seeds, Fertilizers, Crop Protection, Farming Tools, Irrigation, Machinery, Organic Products and Animal Feed. Farmer-only tabs include My Farm, Farm Tools and Equipment Rental.
- **Seller** – sees seller management tabs only: Dashboard, Products, Orders and Rentals. Sellers use the Add Product form to list products into the appropriate customer or farmer category.

Category visibility is stored with each category using its `audience` (`customer` or `farmer`). Existing databases are upgraded automatically by `backend/migrate.py`, so the project does not require a database reset.

## Farmer tools (`/tools`)

- **Crop Doctor** (`/crop-doctor`) – pick symptoms for a general guide (works offline, no key). With `ANTHROPIC_API_KEY` set you can also upload a leaf photo for an AI check (photos are processed in memory and never stored). Guidance only: it gives no pesticide doses and points to the product label / local KVK.
- **Equipment Rental** (`/rentals`) – day-rate booking with availability by date, refundable deposit, booking requests that owners confirm/reject, "My Rentals" with cancellation. Payment is made to the owner directly.
- **Weather & Advisory** (`/weather`) – 7-day forecast and spraying / irrigation / heat advice from the free Open-Meteo service (no key; needs internet).
- **Fertilizer Calculator** (`/fertilizer-calculator`) – urea, DAP and potash per acre/hectare with a split schedule and matching products. Uses typical per-acre NPK guidelines; always follow a soil test and your state recommendation.

## Coupons and invoices

- Checkout has a **coupon box**. Demo codes: `AGRO10` (10% up to ₹300, min ₹500), `KISAN100` (₹100 off above ₹999), `WELCOME50` (₹50 off above ₹300). Each customer can use a code once. Admins create/disable codes at `/admin/coupons`. The discount is applied to the payable total; GST is computed before the coupon.
- **Download Invoice** on any order page gives a PDF (needs `reportlab`, included in `requirements.txt`; run `pip install -r requirements.txt` again if you upgraded). The PDF shows amounts as "Rs." because standard PDF fonts have no ₹ symbol.

## AI assistant

A floating **Ask AI** button (bottom-left) opens a chat that helps with product search ("tomato seeds"), crop tips, delivery/payment/returns questions, pincode checks and order status. It shows product cards with an *Add to Cart* button, supports voice input in Chrome/Edge/Safari, and replies in the language chosen in the navbar.

- **Basic mode (default, no setup):** answers come from your own catalogue and the signed-in customer's orders.
- **AI mode:** set an Anthropic API key and answers are generated by Claude, grounded in your catalogue and the customer's own orders (it is told not to invent products or prices). If the call fails it falls back to basic mode automatically.

```bash
# Windows PowerShell
$env:ANTHROPIC_API_KEY="your_key"
# macOS / Linux
export ANTHROPIC_API_KEY="your_key"
# optional: $env:ANTHROPIC_MODEL="claude-sonnet-5-5"
python app.py
```

Code: `backend/assistant.py`, `static/js/assistant.js`, `static/css/assistant.css`, `templates/_assistant.html`. Messages are limited to 500 characters and 30 per 10 minutes per IP.

## Order tracking map

Open any order (My Orders → order) to see **Track on Map**: seller warehouse → regional hub(s) → delivery address, a vehicle marker at the parcel's position, distance, estimated delivery date and a **My location** button. Leaflet and the dark CARTO/OpenStreetMap tiles load from the internet.

**Important:** the parcel position is *estimated from the order status* (Placed/Confirmed/Packed at the seller, Shipped at a hub, Out for Delivery near the address, Delivered at the address) using a built-in list of Indian districts (`backend/geo.py`). It is not live GPS. For real tracking, return courier coordinates from `build_tracking()` in `backend/tracking.py`. Customers see their own orders, sellers see orders containing their products, admins see all. If a district isn't in the built-in list, the delivery point falls back to the state centre and the map says so.
